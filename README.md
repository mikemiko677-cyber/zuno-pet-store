# ZUNO 🐾

### Modern Pet Care, Reimagined.

ZUNO is a modern, responsive e-commerce website designed around useful products for cats, dogs, and the people who care for them.

The project focuses on a clean shopping experience, strong visual design, responsive layouts, and an interactive homepage experience.

🌐 **Live Website:**  
https://mikemiko677-cyber.github.io/zuno-pet-store/

---

## About ZUNO

Life with pets can get messy.

ZUNO is designed around a simple idea: make everyday pet care easier through useful, thoughtfully selected products and a simple online shopping experience.

The current store focuses on two product categories:

- 🐱 Cat products
- 🐶 Dog products

---

## Featured Products

### 🐱 Smart Self-Cleaning Litter Box

A modern litter solution designed to make everyday cat care easier and cleaner.

### 🐶 Waterproof Pet Car Seat Cover

A practical waterproof seat cover designed to help protect a vehicle while keeping dogs comfortable during travel.

## Interactive Homepage

One of the main features of ZUNO is its interactive hero section.

The homepage features:

- A cat
- A dog
- An interactive food bowl
- Mouse interaction
- Touch interaction for mobile devices
- Animal movement based on the bowl position
- Responsive animations

The experience was created using JavaScript without requiring a large front-end framework.
